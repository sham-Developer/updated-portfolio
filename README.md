# Sham R — Next-Level Software Developer & Team Leader Portfolio

A high-performance, futuristic portfolio web application crafted for **Sham R** (Software Team Leader & Developer). Built with React 19, Vite, and custom Vanilla CSS design system, featuring live interactive project simulators, an interactive terminal / command runner, dynamic constellation canvas background, Web Audio micro-interactions, and instant printable CV generation.

---

## ⚡ Live Features & Highlights

1. **Interactive Constellation Canvas Background**
   - Real-time starry particle mesh responding dynamically to mouse gravitational forces and cursor movements.

2. **Futuristic 3D Developer Hologram**
   - Live 3D cursor-tracking perspective tilt card showcasing TypeScript configuration of Sham's engineering stack, team size, and metrics.

3. **Live Interactive Project Simulators**
   - **OpenCV Alloy Wheel Gap Inspector**: Real-time simulation of industrial wheel rotation, laser scanning line, frame latency telemetry, spoke defect injection, and bounding box color statuses (Pass, Reject, Warn).
   - **Interactive 3D Pattern & Mockup Visualizer**: Real-time 3D CSS perspective rotation, texture pattern switcher (Cyber Hex, Circuit, Aurora, Matrix), emissive glow sliders, and wireframe mode.
   - **Enterprise CRM Operations Suite**: Interactive multi-stage Kanban lead advancement and live GPS field agent location radar.

4. **Interactive Terminal & Command Palette (`Ctrl + K`)**
   - Full keyboard-driven CLI interface supporting commands: `help`, `projects`, `skills`, `experience`, `contact`, `download-cv`, `matrix`, `clear`, and `whoami`.

5. **Curriculum Vitae Viewer & PDF Generator**
   - Printable modal view formatted with executive styling for seamless 1-click printing or PDF export.

6. **Web Audio Synthesizer Micro-Interactions**
   - Built-in zero-dependency Web Audio oscillator sound effects for button clicks, hovers, and confetti celebrations (with navbar mute toggle).

7. **Interactive Skills Radar & Filter**
   - Real-time instant search input and domain tabs (Frontend, Backend, Mobile, Databases, Cloud & DevOps, Tools).

8. **Contact & Collaboration Hub**
   - 1-click clipboard copy with toast feedback for email (`shamamal622@gmail.com`) and phone (`+91 9940846749`), plus an interactive message form with quick intent pills.

## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the localhost URL shown in the terminal (typically `http://localhost:5173` or `http://localhost:5174`).

---

## 📦 Production Build & Deployment

To create an optimized production bundle:
```bash
npm run build
```
The output files will be created in the `dist/` directory, ready for deployment to **Vercel**, **Netlify**, or **GitHub Pages**.

### Deploy to Vercel (Recommended):
```bash
npx vercel
```
Or connect this Git repository directly to [Vercel](https://vercel.com).
